# Social Enterprise Ethiopia Mobile App

A secure, cross platform mobile application built to streamline membership onboarding, fee tracking, renewal workflows, and digital certification for social enterprises on the go.

## Core Mobile Features
- Mobile Authentication & Onboarding: Secure sign-up/login with biometric support options and multi-step organizational registration wizard.
- Member Dashboard & Status Hub: Live membership status card, countdown to renewal, push notification feed, and quick action buttons.
- Digital Wallet & Fee Payments: Mobile friendly fee calculation, digital payment gateway integration (Telebirr/CBE/Banks), and receipt uploads.
- QR Code Certificate Scanner: Built in camera scanner for instant public or official certificate authenticity verification.
- Role Based Mobile Views: Dedicated interfaces for Members, Finance Officers, and Approvers to review applications and verify payments on mobile.
